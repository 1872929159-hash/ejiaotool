# 东阿阿胶京东营销合规词库

> 针对**东阿阿胶**京东官方旗舰店营销场景的违禁词/敏感词/平台规则库

## 核心特性

**`product_type_rules` 字段**：同一词汇在不同产品类型下风险等级不同，这是本词库的核心创新。

例如"补血"一词：
- 中药饮片阿胶 → **L0 允许**（药典记载"补血滋阴"功效）
- 蓝帽子保健食品 → **L1 禁止**（应使用批文功能"改善营养性贫血"）
- 普通食品阿胶糕 → **L1 禁止**（普通食品不得宣称任何功效）
- OTC药品复方阿胶浆 → **L0 允许**（按说明书功能主治使用）

## 词条结构说明

每条词条包含以下核心字段：

| 字段 | 说明 |
|------|------|
| `id` | 全局唯一ID，如 ADV-ABS-00001 |
| `word` | 违禁/敏感词汇 |
| `pinyin` | 拼音（用于谐音变体检测） |
| `category_l1` | 一级分类（ADV/EFF/FMD/PLT/EJ） |
| `category_l2` | 二级分类（如 EFF-BLD 补血类） |
| `risk_level` | 默认风险等级（L1/L2） |
| `product_type_rules` | **核心字段**：四种产品类型各自的风险等级和说明 |
| `legal_basis` | 法律法规依据（引用规则库条款） |
| `variants` | 变体词列表（同义/谐音/扩展） |
| `compliant_alternatives` | 合规替代词建议 |
| `white_list_contexts` | 白名单上下文（该词可合法使用的场景） |
| `tags` | 标签（如"阿胶高频误用""直播高风险"） |

## 使用方法

### 1. 文本检测流程

```
输入文本 + 产品类型标识
    ↓
遍历词库entries
    ↓
对每个词条：
  1. 检查word和variants是否出现在文本中
  2. 查看product_type_rules[产品类型].risk_level
  3. 如果是L1 → 拦截，输出违规位置和建议
  4. 如果是L2 → 预警，提示需要资质佐证
  5. 如果是L0 → 放行
    ↓
输出检测报告
```

### 2. 产品类型标识

在检测前需确定当前商品的产品类型：

| 产品类型代码 | 对应产品 | 确定方式 |
|-------------|---------|---------|
| `tcm_herb` | 阿胶块、阿胶珠 | 京东后台类目=中药饮片 |
| `health_food` | 阿胶口服液、阿胶胶囊 | 蓝帽子批文号 |
| `regular_food` | 阿胶糕、阿胶枣、阿胶粉 | 京东后台类目=普通食品 |
| `otc_drug` | 复方阿胶浆 | OTC标识/药品批准文号 |

### 3. 检测示例

```python
import json

with open('data/final/lexicon/dong-e-ejiao-compliance-lexicon.json', 'r', encoding='utf-8') as f:
    lexicon = json.load(f)

def check_text(text, product_type):
    """检测文本合规性"""
    violations = []
    for entry in lexicon['entries']:
        word = entry['word']
        ptr = entry.get('product_type_rules', {})
        if product_type in ptr:
            risk = ptr[product_type].get('risk_level', 'L3')
            if risk in ('L1', 'L2') and word in text:
                violations.append({
                    'word': word,
                    'risk_level': risk,
                    'category': entry['category_l2'],
                    'description': entry['description'],
                    'note': ptr[product_type].get('note', ''),
                    'alternatives': entry.get('compliant_alternatives', {})
                })
    return violations

# 示例：检测阿胶糕（普通食品）详情页文案
result = check_text("东阿阿胶糕，补血养颜，美容驻颜", "regular_food")
# 结果：命中"补血"(L1)、"美容养颜"(L1)、"淡斑"(无) 等
```

## 风险等级定义

| 等级 | 名称 | 处理策略 |
|------|------|---------|
| L0 | 允许 | 该产品类型下可使用，需确保符合具体法规要求 |
| L1 | 拦截级 | 禁止使用，命中即违规，必须修改 |
| L2 | 预警级 | 需提供资质/证据佐证，或需人工审核确认 |
| L3 | 提醒级 | 存在风险，建议优化表述（本版词库暂未使用） |

### 保健食品特殊要求

蓝帽子保健食品广告**必须**：
1. 标注蓝帽子标识
2. 显著标明"**本品不能代替药物**"
3. 功能宣称与批文**完全一致**
4. 不得含有功效保证（如"100%有效"）
5. 不得涉及疾病预防治疗功能
