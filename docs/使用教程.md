# 东阿阿胶合规检测工具 · 使用教程

> 本教程教你从零开始用上这个检测工具。照着做就行，不用懂电脑、不用懂代码。

---

## 这个工具是干什么的？

**一句话：帮你检查营销文案里有没有违规词，有的话告诉你怎么改。**

比如你写了一句商品文案"东阿阿胶糕，补血养颜，最正宗的阿胶"，复制粘贴进工具，点一下检测，它就会告诉你：
- "补血" → 普通食品禁止宣称功效，建议改成"含阿胶成分"
- "美容养颜" → 所有产品都禁止，建议删除或改成"含阿胶成分的传统美食"
- "最正宗" → 广告法绝对化用语，建议改成"道地阿胶"


**怎么打开：**
- 方法A（推荐）：用鼠标**双击**这个文件，它会自动用浏览器（Chrome/Edge/360浏览器都行）打开

**打开后你应该看到：**

### 步骤2：选择产品类型

**为什么要选产品类型？**

因为东阿阿胶有4类产品，每一类受不同法律管，能说的话不一样。比如"补血"这个词：
- 阿胶块（中药饮片）→ ✅ 能说
- 阿胶口服液（蓝帽子）→ ❌ 不能说（要用"改善营养性贫血"代替）
- 阿胶糕（普通食品）→ ❌ 绝对不能说
- 复方阿胶浆（OTC）→ ✅ 能说

**怎么选：**
在第一个卡片里，有4个按钮，点一下你要检测的那类产品对应的按钮：

| 按钮 | 对应产品 |
|------|---------|
| 阿胶块/阿胶珠 | 中药饮片类（按药典管理） |
| 阿胶口服液/胶囊 | 蓝帽子保健食品 |
| 阿胶糕/阿胶枣/阿胶粉 | 普通食品（最严格） |
| 复方阿胶浆 | OTC药品 |

**选好后你应该看到：**
- 被选中的按钮边框变成酒红色，背景变成浅粉色
- 按钮下面出现一行粉底文字，比如"当前选择：阿胶糕/枣/粉（普通食品）"
- 下面"开始检测"按钮从灰色变成可以点击的酒红色

**看结果：**

## 第二章 看懂检测结果

### 三个颜色代表什么

| 颜色 | 含义 | 你该怎么办 |
|------|------|-----------|
| 🔴 红色 L1 拦截级 | 必须修改，不改会被罚 | **一定要改**，用建议的替换词或删除 |
| 🟡 黄色 L2 预警级 | 需提供证明才能用 | 要么提供证明材料，要么改掉 |
| 🟢 绿色 | 可以发布 | 没查到违规词，可以放心用 |

### 每条违规卡片各字段含义

每检测到一个违规词，会出现一张卡片，包含这些信息：

```
┌─────────────────────────────────────────┐
│ 最正宗                          [L1拦截级]│  ← 违规词 + 风险等级
│                                         │
│ 分类：广告法-绝对化用语                  │  ← 属于哪类违规
│ 原因：使用"最"字构成绝对化品质表述...    │  ← 为什么违规
│                                         │
│ 《中华人民共和国广告法》第九条第(三)项   │  ← 法律依据（灰底框）
│ 广告不得使用"最佳"等用语                 │  ← 被罚的时候这就是证据
│                                         │
│ 说明：中药饮片同样禁止                   │  ← 产品类型相关说明（蓝底框）
│                                         │
│ 建议替换为（点击可复制）：               │  ← 合规替代词（绿底框）
│ [道地阿胶] [品质阿胶] [正宗阿胶(需证明)] │  ← 点一下就能复制走
│                                         │
│ 白名单（以下情况可使用）：序号表述...    │  ← 特殊情况能用（灰底小字）
└─────────────────────────────────────────┘
```

### 怎么用"建议替换词"

这是工具最有用的功能。每个违规词旁边都有绿底的"建议替换为"区域：

1. 看到建议词（比如"道地阿胶""品质阿胶"）
2. **用鼠标点一下**你想用的那个词
3. 屏幕上方会弹出绿色提示"已复制：道地阿胶"
4. 回到你的文案里，把违规词删掉，**Ctrl+V粘贴**替换词进去
5. 搞定！

> 💡 如果某个词没有建议替换词，说明这词没有合规替代，**直接删除**最安全。

## 第三章 怎么改才合规

### 三步改稿法

**第一步：看"建议替换为"**
- 有建议词 → 点击复制，粘贴回去替换违规词
- 没建议词 → 直接删除违规词

**第二步：看"说明"（蓝底框）**
- 这里会解释**为什么你这类产品不能用这个词**
- 比如"普通食品禁止宣称任何功效，'补血'绝对禁止"
- 帮你理解规则，下次就知道怎么写了

**第三步：看"白名单"（如果有）**
- 有些词在特殊情况下可以用
- 比如"第一"在"第一步骤"这种序号表述里可以用
- 对照看看你的文案是不是属于白名单情况

### 改完之后怎么办

把所有🔴红色违规词都改掉（必须改），🟡黄色违规词要么改要么准备证明材料，然后再粘贴进工具检测一遍。**直到出现绿色"可以发布"**，就可以放心用了。

## 第四章 实战演练：3个真实案例

### 案例1：阿胶糕详情页文案（普通食品）

**原始文案：**
> 东阿阿胶糕，补血养颜，美容驻颜，最正宗的阿胶，百年传承工艺，100%纯正

**检测结果：**
- 🔴 最正宗 → 改成"东阿原产阿胶"
- 🔴 100%纯正 → 改成"纯正阿胶"
- 🔴 补血 → 改成"含阿胶成分"（普通食品不能说功效）
- 🔴 美容驻颜 → 改成"传统滋补美食"
- 🟡 正宗 → 需提供东阿原产地证明
- 🟡 百年传承 → 改成"传统工艺"

**修改后文案：**
> 东阿阿胶糕，含阿胶成分的传统滋补美食，东阿原产阿胶，传统工艺，纯正阿胶

**再检测：** ✅ 绿色通过，可以发布

---

### 案例2：阿胶块直播话术（中药饮片）

**原始文案：**
> 我们这个阿胶块最正宗，补血滋阴效果好，疗效显著，完爆其他品牌

**检测结果：**
- 🔴 最正宗 → 改成"道地阿胶"
- 🔴 疗效 → 中药饮片广告不得使用"疗效"，直接删除
- 🔴 完爆 → 贬低同行，违反反不正当竞争法，直接删除
- 🟡 正宗 → 需提供道地药材证明
- ✅ 补血滋阴 → 中药饮片可使用（药典记载），放行

**修改后话术：**
> 我们这个阿胶块，道地阿胶，补血滋阴，品质保证

**再检测：** ✅ 绿色通过，可以直播

---

### 案例3：阿胶口服液新品标题（蓝帽子保健食品）

**原始文案：**
> 东阿阿胶口服液 补血增强免疫力 改善贫血 美容养颜

**检测结果：**
- 🔴 补血 → 蓝帽子要用批文功能"改善营养性贫血"，不能用"补血"
- 🔴 美容养颜 → 批文未含此功能，删除
- 🔴 改善贫血 → 应使用完整批文表述"改善营养性贫血"
- ✅ 增强免疫力 → 批文已批准，可使用（但需标注"本品不能代替药物"）

**修改后标题：**
> 东阿阿胶口服液 增强免疫力 改善营养性贫血 本品不能代替药物

**再检测：** ✅ 绿色通过，可以上架

> 💡 蓝帽子保健食品广告**必须**标注"本品不能代替药物"警示语。

## 第五章 常见问题FAQ

### Q1：没查出违规词，是不是就一定安全？

**不一定。** 本工具内置67条已知违规词，但：
- 法规会更新，新词可能没收录
- 有些表述要看上下文语境，工具判断不了
- 工具只查文字，图片里的文字查不到

**建议：** 工具查完没问题后，上架前再人工过一遍。尤其是直播话术，主播容易即兴发挥说出违规词。

---

### Q2：工具说违规，但我确定能这么用怎么办？

看违规卡片里的**"白名单"**字段和**"说明"**字段：

- 如果有白名单，对照看看你的情况是否属于白名单场景
- 如果你有相关资质证明（比如蓝帽子批文、地理标志证明、有机认证），那黄色预警级（L2）的词可以用
- 红色拦截级（L1）的词是法律明令禁止的，**即使有证明也不能用**

**拿不准的时候：** 保守起见，改掉比被罚强。

---

### Q3：词库会不会过时？怎么更新？

**会过时。** 京东平台规则和法律法规会更新，建议：
- 每3-6个月检查一次词库是否需要更新
- 关注京东规则中心（rule.jd.com）的规则变更通知
- 如果发现新的违规词不在词库里，可以记录下来，下次更新时补进去

更新词库需要找技术人员修改JSON文件，然后重新生成工具。

---

### Q4：可以在手机上用吗？

**可以。** 把HTML文件发到手机上（微信传给自己或发到文件传输助手），用手机浏览器打开即可。界面会自动适配手机屏幕。

但建议**优先在电脑上用**，因为复制粘贴文案、点击复制建议词，电脑操作更方便。

---

### Q5：一次能检测多长的文案？

**没有限制。** 无论多长都能检测。但建议：
- 商品标题/卖点：直接整段粘贴
- 详情页文案：分段粘贴，一段一段检查更清晰
- 直播话术：按段落或按场次粘贴

---

### Q6：检测出来的违规词位置在哪里看？

在结果最下方有一个**"标红后的文案预览"**区域，原始文案里的违规词会被标成红色（必须改）或黄色（需谨慎），一眼就能看到在哪里。
